# Accessibility

Target WCAG 2.2 AA through semantic HTML, accessible names, keyboard reachability, visible focus, clear errors and status announcements. TanStack Table integrations still require accessible table structure and navigation.

Respect reduced-motion preferences in Framer Motion and preserve functionality when animation is reduced. Test zoom, contrast, long text, screen-reader journeys and all asynchronous states. Use automated checks plus manual review; library use alone does not establish conformance. Browser/assistive-technology matrix is TBD.
